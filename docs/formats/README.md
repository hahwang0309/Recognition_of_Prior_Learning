# 확정 보고서 포맷 (원본 보존)

연구팀이 회람·확정한 보고서 포맷의 **원본**이다. 앱의 보고서는 이것을 기준으로 만든다.

| 파일 | 구현 |
|---|---|
| `trackA_보고서.html` | `services/report/track_a_report.py` |
| `trackB_보고서.html` | `services/report/evidence_report.py` |

## 고치지 말 것

CSS 변수·클래스명·마크업 구조·범례 문구·아이콘·색은 원본 그대로 옮겼다.
보기 좋게 만들려고 임의로 바꾸지 않는다. 바꿔야 할 이유가 생기면 연구팀에
먼저 물어보고, 이 폴더의 원본과 구현을 같이 고친다.

원본은 시나리오 4건을 한 문서에 늘어놓은 설계 시안이고, 앱은 접수 한 건을
그린다. 그 차이(문서 하나 = 카드/섹션 하나)만 다르다.

## 특히 지킬 것 — 히트맵

**Track A 가로 막대**
- 척도는 카드 안에서 공통: `max(요구, 이수)` 전체 최대값
- 빨간 실선 = 요구시간, 점선 = −50% 하한
- 색만으로 뜻을 전하지 않는다: 아이콘(●▲■○) + 상태 텍스트 상시 표기,
  시간부족에는 빗금. 적록색약(deutan)에서 초록·빨강은 ΔE 4.1로 구분이 어렵다

**Track B 격자 히트맵**
- 가로축 = 능력단위, 세로축 = 능력단위요소 번호(**큰 번호가 위**), 칸 색 = 권고 구분
- 아이콘: R0 ★ · R1 ● · R2 ▲ · R3 ■ · R4 ◆ · R5 ○
- 빈 칸은 `.hc.empty` (배경 없음)
